# Nation Path

2D пошаговая стратегия на гексагональной карте.

## Описание

Nation Path — это игра в жанре пошаговой стратегии, где игрок управляет фракцией на карте из шестиугольных регионов. Карта представлена в виде большого шестиугольника, плотно заполненного мелкими клетками. Каждая клетка — отдельный регион, который можно захватить, улучшить или использовать для сбора ресурсов.

Карта разделена на 4 цветные зоны (красная, синяя, зелёная, розовая) и центральную нейтральную область. Цель игрока — расширить свою территорию, собирать ресурсы и одержать победу над противником.

## Технологии

- Godot 4.7.2 (Mono)
- C# / .NET 8.0 (Godot.NET.Sdk 4.7.2)
- 2D рендеринг (D3D12)
- Мультиплеер: ENet (UDP)

## Управление

| Клавиша | Действие |
|---------|----------|
| Колёсико мыши | Приближение / отдаление |
| Правая кнопка мыши + движение | Перемещение камеры |
| F | Центрирование камеры на карте |
| F11 | Полноэкранный режим |
| Левая кнопка мыши | Выбор армии / перемещение / выбор региона |
| Правая кнопка мыши | Отмена выбора армии / региона |

## Возможности

- Гексагональная карта с кубическими координатами (R=5, 61 клетка)
- 4 цветные фракции + нейтральная зона
- Экран выбора государства перед началом игры
- Столицы государств (чёрные квадраты): Москва, Париж, Вашингтон, Лондон
- Армии: создание во вкладке «Армия» справа (слайдер 10–100 + тип, сразу в столицу), выбор, перемещение по соседним клеткам
- Солдаты определяют урон (1–100), HP всегда 100 макс., реген 2.0/с; стоимость `soldiers / 10 * 20` золота
- Битвы: армия vs армия (раунд 0.7с, бой ~8–11с); урон от соотношения сил; защитник получает −30% урона; остановка при ≤10 HP; отступление раненых; групповые бои
- Захват территорий: пустые — без боя, вражеские — через бой
- Экономика: стартовое золото 10; базовый доход 2/5с; шахты (доход 5/5с, цена растёт 10/20/30/40/50, макс. 5, стройка 5с)
- Наука: очки (+1/5с + университеты за upkeep), дерево 11 тешек полосами (война + экономика, юниты открываются техами)
- Дипломатия: нейтралитет/война/пакты (5 мин), закрытые границы, вкладка-сплит
- Армии: цена растёт с числом своих войск (×(1 + 0.25 × N))
- Укрепления столиц: уровни 0–3 (15/30/50), −15% входящего урона за уровень
- Информационная панель региона (правый нижний угол)
- Стacking нескольких армий на одной клетке
- Ограничения перемещения камеры
- Сетевая игра 2–4 игрока: ENet клиент-сервер (хост = игрок 1), лобби (IP + LAN-обнаружение), автоназначение наций, игра через Radmin VPN
- ИИ противник: одиночка — все чужие нации (Легко/Норма), сеть — добор ботами в лобби
- Победа/поражение: потеря столицы = выбывание; экран исхода со статистикой, рестарт, наблюдатель
- Звуки (процедурный синтез, без файлов) и эффекты: тряска камеры, вспышки урона и захвата
- Режим бога (только одиночка, кнопка в меню): управление всеми странами, всё бесплатно, индикатор в HUD

## Запуск

### Одиночная игра

1. Установи Godot 4.7 Mono (.NET)
2. Открой проект
3. Нажми Play (F5)

### Сетевая игра (2–4 игрока)

1. Хост: Play → "Сетевая игра" → "Создать сервер" (порт 7000, число игроков)
2. Клиент: "Сетевая игра" → введи IP хоста и порт → "Подключиться" (или "Поиск в LAN")
3. Хост нажимает "Начать игру", когда все подключились
4. Нации назначаются автоматически: хост — Красный, остальные по порядку пиров

На ПК хоста открой UDP-порты в firewall:

```powershell
netsh advfirewall firewall add rule name="NationPath Game" dir=in action=allow protocol=UDP localport=7000
netsh advfirewall firewall add rule name="NationPath Broadcast" dir=in action=allow protocol=UDP localport=7001
```

### Игра через интернет (без VPN)

Код уже работает по любому IP — нужен только доступ до хоста извне:

1. Хост: в лобби кнопка **"Мой внешний IP"** → IP показывается и копируется в буфер → отправь другу
2. На роутере хоста пробрось **UDP 7000–7001** на локальный IP ПК (NAT / Port Forwarding / Virtual Server — зависит от роутера)
3. Друг вводит внешний IP хоста и порт 7000 → "Подключиться"
4. Проверка — только фактическое подключение (UDP не проверяется пингом портов; неверный IP = таймаут 10с)

Не сработало — смотри диагностику:
- IP на роутере начинается с `10.`, `100.64–127.`, `192.168.` → **серый IP (CGNAT)** у провайдера: проброс невозможен в принципе
- Крайняя мера: DMZ на IP ПК (открывает все порты — только на время игры!)
- Запасной путь — **Radmin VPN** (виртуальная LAN, ничего пробрасывать не надо)

Обязательно: хост и клиенты на **одинаковых билдах** (протокол v1, иначе рассинхрон).
