# Nation Path — Roadmap до MVP

## Текущее состояние (Alpha — прототип)

### Что реализовано
- [x] **Карта**: генерация 61 клетки (R=5), cube coordinates, 4 цветные зоны + белая нейтральная (7 клеток)
- [x] **Регионы**: `Region.cs` — `Id`, `RegionName`, `Center`, `OwnerId`, `OwningNation`, `Gold`, `GarrisonPower`, `Neighbors`
- [x] **Соседство**: автоматическое вычисление по расстоянию между центрами гексов
- [x] **Камера**: зум колёсиком, панорамирование ПКМ, F — центр, F11 — fullscreen, ограничения перемещения
- [x] **Окно**: 1280×720, windowed, D3D12
- [x] **Нации**: `Nation.cs` — 4 государства (Красный, Синий, Зелёный, Розовый), выбор на экране старта
- [x] **GameManager**: autoload singleton (`PlayerNationId`, `IsMultiplayerGame`, `TotalPlayers`, `PeerNationMap`, экономика `Gold`/`Mines`/`BuildTimers`)
- [x] **Экран выбора**: `NationSelect.cs` — 4 цветные кнопки, переход на Main.tscn; в сети — автоназначение нации (`peerId - 1`)
- [x] **Столицы**: чёрные квадраты по центру территории каждого государства, имена: Москва, Париж, Вашингтон, Лондон; создание армий только в столице
- [x] **Клик по региону**: выделение зелёным, вывод информации (название, владелец)
- [x] **Панель информации**: `RegionPanel.cs` — в правом нижнем углу; инфо региона, шахты, форты, инфо армии, кнопка совмещения (вкладки)
- [x] **Совмещение армий**: Shift-выбор пары (одна нация/клетка/тип, вне боя) → кнопка «Совместить» с превью (излишек свыше 100 сгорает); HP — среднее взвешенное; команда `MergeArmies` с валидацией на сервере
- [x] **Вкладки справа**: `SideTabs.cs` — Дипломатия (сплит: список/инфо/война/пакт) / Исследования (настоящие) / Армия; создание войск сразу в столицу (слайдер + типы, выбор нации в режиме бога, блок наблюдателю)
- [x] **Дипломатия**: `RelationState` (Neutral/War/Pact), матрица `Relations` (ключи min*10+max), старт — все нейтральны; пакты 300с с истечением в `CollectIncome`; пакт — только по акцепту (`PactOffers`, таймаут 60с, отзыв, автопринятие ботов); пакт блокирует войну, мирный договор выводит из войны; модалка объявления войны (`RpcAnnounceWar`, слой 70); закрытые границы (в чужое без войны нельзя), пакт = проход без боёв; вкладка-сплит (флаги, статусы, списки войн/пактов, таймер, кнопки по состоянию); команды `SetRelation`/`ProposePact`/`AnswerPact` (валидация отправителя) + `RpcSyncRelation`/`RpcSyncPactOffer`/`Withdraw`, протокол v4; ИИ объявляет войны сам, пакты чтит
- [x] **Наука**: валюта ОИ (`Research`, тик +1/5с); университеты (30з, 5с, макс. 2, +2 ОИ/5с, upkeep 5з/очко, авто-кап по золоту); дерево 11 тешек полосами (война: Оружие I/II, Дисциплина, Пехота, Ветераны/Тактика/Резервы, Элита [требует Резервы+Оружие I+Дисциплину]; экономика: Торговля→Рекрутство→Логистика); исследование 6 дней (оплата вперёд, один слот); юниты за наукой (ополчение базовое, `CanRecruit` + валидация сервера, бог в обходе); открытая вкладка блокирует ЛКМ по карте; очередь строек (`BuildOrders`, фикс халявных шахт за форты); синк — `RpcSyncEconomy` (+очки/универы/маска/заказ), команды `Research`/`BuildUniversity`, протокол v2; ИИ-Норма строит универ и покупает техи
- [x] **Армии**: `Army.cs` — кружок + текст (сила), цвет по владельцу, обводка при выборе; `Soldiers` (1–100, определяют урон), `HP` (макс. 100, реген 2.0/с); стоимость `soldiers / 10 * 20` золота
- [x] **Создание армий**: через панель региона в столице, проверка золота
- [x] **Перемещение**: по соседним клеткам, проверка соседства; лимит 2 своих армии / 200 своих солдат на клетке (шаг/отступление/создание); стрелка прогресса шага у каждой идущей армии
- [x] **Стacking**: несколько армий на одной клетке (смещение по кругу)
- [x] **Битва**: армия vs армия; детерминированный рандом (сид боя+раунда) + серверный синк HP/добиваний; урон от соотношения эффективной силы (база 8 × кламп [0.25, 4], потолок 8 HP/раунд); правило красного квадрата (≤25 HP на начало боя + проигрыш = разбита без отступления); наступление — только после ухода проигравшего; защитник получает −30% урона; остановка при ≤10 HP; раненые отступают на соседнюю свою клетку (иначе гибнут); групповые бои нескольких атакующих; темп — раунд 0.7с, любой бой ~8–11с; шаг на клетку 1.5с всегда (ходьба, отступление, наступление после победы)
- [x] **Захват территорий**: пустая клетка — без боя, вражеская армия — бой до гибели одной из сторон
- [x] **Отмена**: ПКМ — сброс выбора армии/региона
- [x] **Экономика**: стартовое золото 10; базовый доход 2/5с; шахты (цена 10, доход 5/5с, макс. 5, стройка 5с); HUD золота
- [x] **Мультиплеер (база)**: `NetworkManager.cs` (autoload) — ENet клиент-сервер 2–4 игрока, хост = игрок 1; `LobbyScreen.cs/.tscn` — создание сервера, подключение по IP, поиск в LAN (UDP broadcast порт 7001, игра — порт 7000), кнопка «Мой внешний IP» (api.ipify.org + копия в буфер), таймаут подключения 10с; `GameState.cs` — `GameCommand`/`CommandType` (CreateArmy, MoveArmy, BuildMine, BuildFort, SelectArmy, DeselectArmy); RPC-синхронизация армий, захватов регионов и экономики; firewall-правила UDP 7000/7001; интернет вручную (проброс портов, гайд в Readme); `export_presets.cfg` (Windows Desktop)
- [x] **Режим бога** (только одиночка, для тестов): кнопка-тоггл в меню, управление всеми странами (армии/шахты в любой столице), всё бесплатно, индикатор «РЕЖИМ БОГА» в HUD
- [x] **Победа/поражение**: выбывание при потере столицы; победа — последний с столицей (одиночка: все 4 столицы; сеть: все соперники-люди); экран исхода со статистикой (время, битвы, потери, захваты), «Ещё раз» (рестарт через RPC) / «В меню»; наблюдатель при выбывании в сети
- [x] **Укрепления столиц**: `Region.FortLevel` 0–3, цены 15/30/50, стройка 5с (общая очередь с шахтой); входящий урон защитнику × (1 − 0.15 × уровень); шевроны на маркере столицы; синк уровня в `RpcSyncRegionCaptured`; команда `BuildFort`
- [x] **Типы войск (лестница)**: `UnitType` (Ополчение ×0.6 цены/×0.8 урона, Пехота база, Элита ×2 цены/×2.5 урона/шаг 1.2с); эффективная сила в формуле боя; селектор типа в панели; тип в `RpcSyncArmyCreated` (несовместимо со старыми билдами)
- [x] **ИИ противник**: `AIPlayer.cs` — мозг-таймер (Легко 8с/только слабее/макс. 3 армии, Норма 4с/равные/макс. 5/шахты+форты); стройка через `Server*`-API, приказы через `QueueArmyMove`, оборона столицы; одиночка — все чужие нации (сложность в меню, в режиме бога выкл); сеть — добор счётчиком в лобби, боты на сервере (Норма), раздача наций через `RpcAssignNation`
- [x] **Звуки и эффекты**: `AudioHub.cs` (autoload, процедурный синтез PCM без файлов: удар, захват, стройка, найм, клик, победа, поражение; mute кнопкой в HUD); в бою — только вспышки урона (звук ударов и тряска отключены); жёлтое кольцо захвата на регионе

## Этап 5 — MVP

### Что должно работать в MVP:
1. Одиночная игра против ИИ **или** сетевая игра 2–4 (реалтайм, авторитет сервера)
2. Карта из 61 региона, 4 фракции + нейтралитет
3. Армии: создание, перемещение, бой
4. Захват территорий
5. Экономика: золото, доход, шахты (Wood/Stone — после MVP)
6. Простейший ИИ: захватывает и атакует (только одиночка)
7. HUD с ресурсами и кнопками
8. Сохранение / загрузка (только одиночка)
