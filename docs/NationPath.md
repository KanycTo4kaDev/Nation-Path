# Nation Path — Полное описание проекта

## Обзор

**Nation Path** — 2D пошаговая стратегия на Godot 4 (C#). Игрок управляет фракцией на карте из шестиугольных регионов, захватывая территории, собирая ресурсы и сражаясь с ИИ-противником.

## Архитектура

### Сцена (`Main.tscn`)

Корневой узел `Main` (Node2D) содержит:
- Скрипт `MapGenerator.cs` — генерирует карту при запуске, армии, битвы, ввод
- Дочерний `Camera2D` со скриптом `CameraController.cs`
- Дочерние `Region` (Polygon2D) — создаются динамически
- `RegionPanel` — UI-панель региона (создание армий, шахты)

Autoload-синглтоны (`project.godot`): `GameManager`, `NetworkManager`.

### Столицы

По одной на нацию, ближайшая к центру своей зоны клетка. Маркер — чёрный квадрат. Имена: Москва (0), Париж (1), Вашингтон (2), Лондон (3). Создание армий — только в своей столице.

### MapGenerator.cs

**Назначение:** Генерация карты-шестиугольника из мелких шестиугольников.

**Экспортируемые параметры:**
- `HexBoardRadius = 5` — радиус большой карты (R=5 → 61 клетка)
- `HexCellRadius = 35f` — размер одной клетки в пикселях

**Алгоритм:**
1. Генерация центров через **кубические координаты** (q, r, s где q+r+s=0)
2. Все клетки где `max(|q|, |r|, |s|) <= R-1`
3. Конвертация в пиксели: `x = radius * √3 * (q + r/2)`, `y = radius * 1.5 * r`
4. Центрирование на экране через `GetViewportRect().Size / 2`
5. Каждая клетка — отдельный `Region` с вершинами и цветом

**Зоны карты:**
- 4 фракции по углу от центра (красный, синий, зелёный, розовый)
- Центральная нейтральная зона (7 белых клеток: центр + 6 соседей)

### Region.cs

**Наследник:** `Polygon2D`

**Поля:**
- `string RegionName` — имя региона ("Region_0" ... "Region_60")
- `int OwnerId` — ID владельца (-1 = нейтральный)

**Метод `Initialize(name, vertices, color)`:**
- Устанавливает имя, вершины полигона и цвет

### CameraController.cs

**Наследник:** `Camera2D`

**Управление:**
| Действие | Ввод |
|----------|------|
| Зум | Колёсико мыши |
| Панорамирование | Правая кнопка + движение мыши |
| Центрирование | Клавиша F |
| Fullscreen | Клавиша F11 |

**Экспортируемые параметры:**
- `ZoomSpeed = 0.1f`
- `MinZoom = 0.3f`
- `MaxZoom = 3.0f`

**Реализация:**
- Зум обрабатывается в `_UnhandledInput` (однократное срабатывание)
- Панорамирование обрабатывается в `_Process` (сравнение позиции мыши между кадрами)
- Fullscreen через `Window.ModeEnum.Fullscreen` / `Window.ModeEnum.Windowed`

## Экономика

Константы (`GameManager.cs`): стартовое золото 10, базовый доход 2/5с, шахта — доход 5/5с, цена растёт 10/20/30/40/50 (`GetMineCost`), макс. 5 шахт на нацию, стройка 5с.

Доход собирается каждые `IncomeInterval` (5с) по всем нациям. Один тик = один день (`GameManager.Day`, с 1). Верхняя плашка по центру: наука слева, «День N» в середине, золото справа. Ховер по плашке — тултип экономики справа-снизу от мышки (доходы/расходы/итого/наука, upkeep пишется в `DayUpkeep`). Шахты строятся через `RegionPanel` в своих регионах. В сети траты синхронизируются сервером через `RpcSyncEconomy`.

## Армии и бой

**Армия (`Army.cs`):** `Soldiers` (10–100, определяют урон), `HP` (макс. 100, реген 2.0/с вне боя). Стоимость создания: база `soldiers / 10 * 20` × тип × наценка за число своих армий `× (1 + 0.25 × N)` (бог — бесплатно). Начальных армий нет — солдаты не регенерируют, только HP.

**Бой:** темп — раунд каждые 0.7с (`BattleRoundDelay`); детерминированный рандом (сид `defender.Id × 1000003 + round`) — все пиры получают одинаковый множитель; сервер синкает HP каждый раунд (`RpcSyncArmyHP`) и добивания (`RpcSyncArmyDestroyed`); урон от соотношения эффективной силы (`солдаты × тип`, Элита ×2.5): база 8 (`BattleBaseHit`) × клампнутое отношение `[0.25, 4]` × рандом — большая армия бьёт сильнее и получает меньше; потолок 8 HP/раунд (`BattleMaxHitPerRound`) держит любой бой в пределах ~8–11с; правило красного квадрата (`Army.CriticalHp` = 25): проигравший защитник, бывший при смерти на начало боя (`DefenderStartHp`), разбивается без отступления; побег с 1 HP — только если до раунда было > 25 HP; выживший защитник отступает всегда, раненый тоже; цена отступления — арьергард 25% солдат, при 0 армия рассыпалась; метка низкого HP (красный квадрат) — при HP≤25, гаснет выше; победивший защитник помечается раненым (реген и продолжение пути); наступление победителей — только после ухода проигравшего (шаг в клетку с отступающим ждёт без стрелки, бой не начинается; после освобождения стрелка появляется с полным замахом); отступление — не в клетку с врагом; защитник получает −30% урона; остановка при ≤10 HP (0 — поражение, 1 — победа, 2 — ничья); победитель-раненый (HP < макс.) помечается `IsWounded`; выжившие отступают (в т.ч. раненые), гибель — только в окружении; групповые бои нескольких атакующих против одного защитника; шаг армии на клетку — персональная задержка (пехота/ополчение 1.5с, элита 1.2с): обычная ходьба, отступление проигравших (`_retreatTimers`, со стрелкой) и наступление после победы (через общий механизм `_Process`); стрелка перемещения у каждой идущей армии — зелёная заливка показывает прогресс до шага, в бою — красная на всю битву (слой `MoveOverlay.cs`, ZIndex 100, поверх гексов).

## Сетевая архитектура

**Топология:** клиент-сервер, хост = игрок 1. Транспорт — ENet (UDP), порт 7000 — игра, 7001 — LAN-broadcast. Лобби: ввод IP + автообнаружение в LAN. Нации назначаются автоматически: `nation = peerId - 1` (хост — Красный). 2–4 игрока. Через интернет — Radmin VPN.

**Поток команды:** клиент шлёт `GameCommand` (`RpcSendCommand`) → сервер валидирует → применяет (`ServerCreateArmy`/`ServerMoveArmy`/`ServerBuildMine`) → рассылает RPC-синк всем.

**RPC-синки:** `RpcSyncArmyCreated`, `RpcSyncArmyMove`, `RpcSyncArmyDestroyed`, `RpcSyncRegionCaptured`, `RpcSyncEconomy`, `RpcSyncArmyHP`, `RpcSyncBattleResult`. Выбор только своих армий в сети; ввод через `_UnhandledInput`, чтобы клики по UI не двигали игру.

**Firewall (хост):** открыть входящие UDP 7000 и 7001.

## Меню-пауза

Кнопка-гамбургер слева вверху (процедурная иконка 44×44, тултип «Меню (ESC)») + ESC: оверлей (затемнение, «Пауза», ряд звука — тоггл ВКЛ/ВЫКЛ + слайдер громкости через Master-bus, «Продолжить», выход). Текст выхода по режиму: одиночка — «Выйти в меню», сеть — «Отключиться» (хост шлёт `RpcServerStopping`). Пауза (`GetTree().Paused`, слою `ProcessMode.Always`) — только одиночка; в сети игра идёт дальше. Пауза снимается перед любым уходом со сцены (смена сцены её не сбрасывает).

## Укрепления столиц

`Region.FortLevel` 0–3, цены 15/30/50 золота (`GameManager.GetFortCost`), стройка 5с в общей очереди с шахтой (`BuildTimers`). Кнопка «Укрепить» в панели столицы (владелец + режим бога; в сети — команда `BuildFort` → `ServerBuildFort` с валидацией). Входящий урон защитнику в регионе с фортом: `× (1 − 0.15 × уровень)` (макс. −45%). Визуал — золотые шевроны под маркером столицы (`_capitalMarkers`, `RefreshCapitalMarkers`). Уровень синхронизируется в `RpcSyncRegionCaptured`.

## Типы войск

Лестница (`UnitType`, характеристики в `UnitStats`): Ополчение (×0.6 цены, ×0.8 урона, шаг 1.5с), Пехота (база, шаг 1.5с), Элита (×2 цены, ×2.5 урона, шаг 1.2с). Лимит: не больше `MaxArmiesPerRegion` = 2 **своих** армий и `MaxSoldiersPerRegion` = 200 **своих** солдат на клетке (`RegionHasRoom`; шаг/отступление/создание; бой и слияние вне лимита). Пути от `FindPath` хранятся без стартовой клетки (первый шаг — сразу в соседнюю). В бою используется эффективная сила (`солдаты × урон_типа`) — и в соотношениях, и в долях. Скорость — персональная задержка шага (`GetMoveDelay`). Тип выбирается в панели (3 кнопки), едет в `GameCommand.Arg3` и `RpcSyncArmyCreated`; буква типа (М/П/Э) и осветление иконки элиты — в `_Draw` (ополчение красится как пехота 1-в-1, отличается только PNG). Протокол версии 2: клиенты разных билдов несовместимы (v2 добавил науку в синк экономики).

## Наука

Валюта ОИ (`GameManager.Research`): базовый тик +1/5с всем. Университет (кнопка в панели столицы): 30 золота, 5с, макс. 2 на нацию, общая очередь с шахтами (`BuildOrders`: mine/uni; форты — мгновенно, вне очереди); каждый +2 ОИ/5с, upkeep 5 золота за очко, при нехватке золота очки режутся (`min(2×универы, золото/5)`). Шкала в HUD (`Золото | Наука`).

6 тешек (маска `TechMask`, тиры по порядку — II требует I): война — Оружие I (+10% урон, 20з+10 ОИ), Оружие II (+20%, 50з+30 ОИ), Дисциплина (реген 2→3/с, 40з+25 ОИ); экономика — Торговля (+2 базовый доход, 20з+10 ОИ), Рекрутство (−15% цены армий, 40з+25 ОИ), Логистика (шаг −0.15с, 60з+40 ОИ). Юниты за наукой: Пехота — тех 6 (30з+15, требует Дисциплину), Элита — тех 7 (80з+60, требует Резервы + Оружие I + Дисциплину); ополчение базовое. Ветки пехоты: Ветераны (8, вверх, меньшие потери, 50з+30), Тактика (9, вниз, +15% вдвоём+, 50з+30), Резервы (10, по стволу, лимит 100→120, 60з+40). Дерево цепочками: война Оружие I → Дисциплина → Пехота (и Оружие I → Оружие II), экономика Торговля → Рекрутство → Логистика. Вкладка — настоящее дерево (`TechTreeView.cs`): квадратные узлы 76px (слоты под текстуры — менять только `MakeNodeTexture`, будущий путь `res://Assets/tech_{id}.png`), ряды Война/Экономика, полосы ±140px, связи по `TechRequires` (серая/жёлтая/зелёная); область дерева в скролле (мин. габарит 1150×660); скролл дерева — колесо + ПКМ-драг; ховер по узлу — тултип (название/эффект/цена/требования/статус). Открытая вкладка блокирует ЛКМ по карте (ПКМ-камера работает) и закрывает меню клетки. Любое открытое меню (вкладки, пауза) останавливает камеру (`CameraController.InputLocked`: панорама, зум, F); игра идёт дальше. Эффекты — мультипликаторы в choke points (бой, доход, реген, цены, шаг). Покупка: вкладка (одиночка/бог — бесплатно, порядок тиров соблюдается), сеть — команда `Research` с валидацией. Синк — расширенный `RpcSyncEconomy` (+очки, универы, маска, заказ). ИИ-Норма строит универ и покупает cheapest-доступный тех; Легко игнорит.

## Текстуры и иконки

`Assets/` (импорт автоматический, в экспорт попадает через `all_resources` + `embed_pck`; грузить только через `GD.Load` — `LoadFromFile` исходников в экспорте не видит). Центр — `GameIcons.cs`: `Get("gold"/"science")` (кеш) + `MakeIcon()` (TextureRect 20px); файла нет — генерированный плейсхолдер (монета/колба), ничего не падает. Файлы: `gold.png`, `science.png` (любой формат/размер ~32px). Иконки стоят везде где цифры валют: HUD, вкладка исследований, панель шахт. Типы войск: `militia.png` / `elite.png` (пехота — `helmet.jpg`); нет файла — плейсхолдер из кода. Требования к своим PNG: прозрачный фон (альфа), иконка по центру ~32–64px, иначе чёрный квадрат. Загрузка — только через `GameIcons.Get` (кеш + лог `[Icons] id: файл W×H / плейсхолдер`); после замены файла перезапустить редактор. Под иконкой армии всегда фирменная рамка: тёмный квадрат в цвет нации + серая обводка — одинаковый «квадрат» у всех типов. Цены в кнопках — текстом.

Протокол версии 3: клиенты разных билдов несовместимы (v3 добавил дипломатию).

## Дипломатия

Модель: `RelationState` (Neutral/War/Pact), матрица `Relations` (ключ пары `min*10+max`), таймеры пактов `PactTimers`, `PactDuration` 300с. Старт мира — все нейтральны (`InitDiplomacy`, рематч сбрасывает); истечение пактов — в `CollectIncome` (детерминировано). Механика: закрытые границы (шаг/бой в чужую owned-клетку без войны — стоп со снятием приказа), пакт = свободный проход без боёв и без захватов (бой mid-pact доигрывается), белые ничейные — всем; пакт блокирует войну (только дождаться истечения), мирный договор — выход из войны в нейтралитет. Действия (`DeclareWarForPlayer`/`MakePactForPlayer`, `ServerSetRelation` с валидацией; война рвёт пакт, штрафа v1 нет): вкладка-сплит (`SideTabs`) — слева нации (флаг-`ColorRect` под будущие текстуры, статус), справа флаг/статус/списки войн и пактов/таймер мм:сс + 2 кнопки (за главную нацию, наблюдатель без кнопок). Сеть: команда `SetRelation` (привязка к нации отправителя через `GetRemoteSenderId`) + `RpcSyncRelation`. ИИ: обходит пакты, объявляет войны сам (`EnsureWarForCell`), предложения игрока принимает молча, первым не разрывает.

## Совмещение армий

Shift-клик по второй своей армии — пара (`_selectedArmy` + `_secondArmy`, кольцо у обеих; предпроверка до ветки приказов, иначе клик перехватывал бы приказ; выбор ближайшей в стаке). Условия: одна нация, одна клетка, один тип, обе вне боя и не отступают. Кнопка «Совместить» в панели региона с превью (`min(100, A+B)`, излишек сгорает); при несовпадении — причина вместо кнопки. HP — среднее взвешенное по солдатам (вниз, макс. 100), `IsWounded = HP < MaxHP`, бесплатно. Сброс пары: ПКМ, приказ, выбор без Shift, смерть/бой/отход (авто-валидация в `_Process`). Сеть: команда `MergeArmies` (ID пары), сервер валидирует (в т.ч. `PlayerId` отправителя), синк — `RpcSyncArmyDestroyed` + `RpcSyncArmyHP`.

## ИИ противник

`AIPlayer.cs` (Node, по одному на нацию-бота): тик мышления — Легко каждые 8с, Норма каждые 4с. Цикл: смерть при потере столицы (узел удаляется) → стройка (`ServerCreateArmy` в столице: Норма — элита 60 при деньгах, иначе пехота 50 / ополчение 30; лимит армий 3/5; шахты, на Норме — форты) → приказы свободным армиям (HP>10, без пути, вне боя): оборона (враг в/у столицы — бить), иначе ближайшая чужая клетка по силам (порог агрессии 0.7/1.0). Ходит тем же API, что игрок. Одиночка: все чужие нации — боты (сложность в меню, `GameManager.AIDifficulty`); режим бога — без ИИ. Сеть: добор счётчиком «Боты» в лобби, боты (Норма) на сервере, ходы через `ServerMoveArmy` (синк клиентам), нации раздаются `RpcAssignNation` до старта (люди по порядку подключения, боты — следующие).

## Звуки и эффекты

`AudioHub.cs` (autoload): 7 процедурных SFX (синтез 16-бит PCM 22 кГц в коде, внешних файлов нет) — удар, захват, стройка, найм, клик, победа, поражение; пул из 8 `AudioStreamPlayer` для полифонии; глобальный mute (кнопка «Звук» в HUD). В бою ударов не слышно и тряски нет — только красные вспышки урона. Эффекты: тряска камеры (`CameraController.AddShake`, в бою отключена), красная вспышка урона на иконке армии (`Army.FlashHit`, 0.25с), жёлтое расходящееся кольцо захвата (`_captureFlashes` + слой `MoveOverlay`, 0.6с).

## Победа и поражение

Потеря столицы = выбывание нации. Победа — остаться последним с столицей: в одиночке нужно взять все 4 столицы, в сети — выбить всех соперников-людей (нейтральные нации не считаются). Решение принимает сервер (`CheckVictory` в `_Process`), исход рассылается `RpcGameOver(winnerId)`, рестарт — `RpcRestartMatch`, уход сервера — `RpcServerStopping`. Выбывший в сети становится наблюдателем (ввод заблокирован, камера и обзор остаются). Экран исхода: затемнение, «Победа!/Поражение», статистика (время, битвы, потери, захваты), кнопки «Ещё раз»/«В меню».

## Математика

### Кубические координаты

Каждый гексагон Represented тройкой (q, r, s) где `q + r + s = 0`.

Для карты радиуса R все валидные клетки:
```
for q in [-(R-1), R-1]:
  for r in [-(R-1), R-1]:
    s = -q - r
    if |s| <= R-1: valid
```

Количество клеток: `3*R² - 3*R + 1`

| R | Клеток |
|---|--------|
| 3 | 19 |
| 4 | 37 |
| **5** | **61** |
| 6 | 91 |

### Конвертация в пиксели (Pointy-top)

```
x = HexCellRadius * √3 * (q + r/2)
y = HexCellRadius * 1.5 * r
```

### Определение зоны по углу

```csharp
angle = atan2(y - centerY, x - centerX)
```

| Угол | Зона |
|------|------|
| [-45°, +45°) | Красный (восток) |
| [+45°, +135°) | Синий (юг) |
| [-135°, -45°) | Зелёный (север) |
| Остальное | Розовый (запад) |

## Известные ограничения

1. **Нет сохранений** — при перезапуске карта генерируется заново
2. **Нет валидации sender** — клиент может прислать команду с чужим `PlayerId`
3. **Нет проверки столицы на сервере** — `ServerCreateArmy` не сверяет регион со столицей
4. **Нет реконнекта** — обрыв = выход из игры
5. **HP в бою не синкается в реальном времени** — только итоги (создание/движение/уничтожение)
6. **Карта генерируется локально у каждого пира** — рассинхрон сида даст разные карты
7. **F11 не работает** во встроенном режиме Godot (нужно открепить окно)
